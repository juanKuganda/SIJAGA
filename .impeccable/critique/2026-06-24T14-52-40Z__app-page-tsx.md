## Anti-Patterns Verdict

**LLM assessment**: Gradient text on 5+ headings, identical card grids (3-card and 4-card patterns), glassmorphism on every container including flat-sitting cards. Reads as AI-assembled from a template.

**Deterministic scan**: 2 gradient-text warnings in globals.css (lines 193, 200).

## What's Working

1. Tonal depth hierarchy (abyss → vault → surface) is clean and consistent
2. Verification result states (verified/revoked/not-found) well-differentiated
3. Component vocabulary (Button, Input, Badge, Card) consistent across page

## Priority Issues

**[P1] Gradient text on every heading**: gradient-text class on 5+ headings. Violates DESIGN.md. Use solid crimson or ink.

**[P1] Identical card grids**: "Apa Itu SIJAGA" (3 cards) and "Fitur Unggulan" (4 cards) same pattern. Vary layout.

**[P2] Glassmorphism overuse**: Every container uses glass treatment. Use glass only for nav and modals; cards get solid vault background.

**[P2] No reduced motion support**: Animations lack @media (prefers-reduced-motion: reduce) fallback.

**[P3] Muted text contrast**: #52525B on #0A0A0F is ~3.5:1, below 4.5:1 WCAG AA.

## Persona Red Flags

**Jordan (First-Timer)**: "NFT Soulbound" unexplained. Verification form below the fold. No visible help.

**Sam (Accessibility)**: animate-fade-in-up with animationFillMode backwards may hide content during keyboard nav. No skip-to-content link.
