## Users

**University Admins**: Manage student credentials, verify wallets, mint NFT degrees, revoke fraudulent credentials. Operate in a dashboard context with frequent CRUD actions.

**Students**: Register Phantom wallets, track credential issuance status, claim NFT degrees. Navigate a portal to check their academic credential lifecycle.

**Employers / Public Verifiers**: Verify degree authenticity via wallet address. No login required; fast, trust-building interaction.

## Product Purpose

SIJAGA is an anti-forgery academic credential verification system for Universitas Tadulako. It issues Soulbound NFT degrees on Solana blockchain, making diplomas tamper-proof and globally verifiable. Success means any employer can confirm a degree's authenticity in seconds, and the university can manage the full credential lifecycle (issue, verify, revoke) with a single tool.

## Brand Personality

**Trustworthy, modern, secure.** Institutional credibility meets blockchain-forward aesthetics. The interface should feel like a bank vault crossed with a sleek SaaS tool: serious enough for a registrar's office, modern enough to signal this isn't legacy software.

## Anti-references

- Generic crypto/Web3 dashboards with neon gradients and excessive glow effects
- Legacy university portals that look like they were built in 2008
- Overly playful fintech apps that undersell the gravity of academic credentials
- Glassmorphism-heavy designs that prioritize style over readability

## Design Principles

1. **Earn trust through clarity**: Every interface element should make the user more confident in the system, not less. Clear status indicators, transparent processes, no hidden states.
2. **Show the chain, don't hide it**: Blockchain integration should be visible and verifiable, not abstracted away. Users should see on-chain proof, transaction links, and wallet addresses.
3. **Efficiency over ceremony**: Admin workflows should be fast and batch-friendly. Students should see their status at a glance. Verification should take seconds, not minutes.
4. **Gravity appropriate to the domain**: Academic credentials are serious. The design should reflect that weight without being intimidating. No playful mascots, no gamification.

## Accessibility & Inclusion

- WCAG 2.1 AA compliance minimum
- Support for reduced motion (prefers-reduced-motion)
- High contrast text on dark backgrounds (4.5:1 minimum)
- Keyboard navigable forms and interactive elements
- Screen reader compatible status indicators
